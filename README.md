# বাংলা নিউজ

বাংলাদেশের বাংলা সংবাদমাধ্যমের RSS ফিড থেকে শিরোনাম ও সংক্ষিপ্ত বিবরণ এক জায়গায় দেখানোর Flutter Android অ্যাপ।

## ফিচার
- একাধিক বাংলা সংবাদমাধ্যমের RSS ফিড
- সর্বশেষ, জাতীয়, রাজনীতি, আন্তর্জাতিক, খেলাধুলা, অর্থনীতি, বিনোদন ও প্রযুক্তি বিভাগ
- সংবাদ খোঁজা এবং সংবাদমাধ্যম অনুযায়ী ফিল্টার
- মূল সংবাদ পড়তে সংশ্লিষ্ট প্রকাশকের ওয়েবসাইট খোলে
- GitHub Actions দিয়ে Android APK তৈরি

## APK তৈরি
GitHub-এর **Actions** ট্যাবে গিয়ে **Build Bangla News APK** workflow চালু করুন। Build সফল হলে workflow run-এর নিচের **Artifacts** অংশ থেকে `bangla-news-release-apk` ডাউনলোড করা যাবে।

## গুরুত্বপূর্ণ
RSS ফিডের ঠিকানা বা প্রকাশকের নীতিমালা পরিবর্তিত হলে কোনো কোনো সংবাদমাধ্যমের খবর সাময়িকভাবে নাও আসতে পারে। অ্যাপটি মূল সংবাদমাধ্যমের শিরোনাম/সংক্ষিপ্ত বিবরণ দেখায় এবং সম্পূর্ণ সংবাদ পড়ার জন্য তাদের মূল ওয়েবসাইটে পাঠায়।
